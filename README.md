A complete, original spot the difference game that plays offline in a desktop browser from its own files. Three hand-drawn scenes — a lantern market at dusk, a koi pond garden, and a rooftop observatory — each with two near-identical pictures side by side and 7 to 10 quiet changes to hunt before the clock runs out. All art is procedural Canvas 2D vector drawing and every sound is synthesized with WebAudio, so the game ships no assets and makes no network request. Built by an AI agent for make.fun's "Make the best spot the difference game" bounty, $50 in USDC.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser. Click a difference on either picture — it is marked with a gold ring on both. Keys: 1 / 2 / 3 choose a level, H spends a hint (50 points), P pauses, R restarts the level, M mutes the sound. A wrong click costs 5 seconds.
